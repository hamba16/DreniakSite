# Image interaction revision ? 1 October 2026

The earlier thumbnail strip, gallery toolbar and detached focused view have been removed. The existing project, sector and leadership cards now form one expanding row. Selecting an original image widens its own card and reveals its original detail; adjacent images remain in view. Mobile uses native horizontal scrolling with snap points and a visible next-card edge. Arrow keys, Home and End move between cards. Direct team-member anchor links select the corresponding card.

Photographic frames are capped at 300px on desktop and 240px on small containers. Inactive desktop photos show a detail preview; the selected image and all mobile images preserve the complete composition. Portraits always retain their complete composition. Reduced motion disables the width and framing transitions. There is only one copy of each image, and all original headings, captions, contact links and credits remain in the source cards.

The rejected `geotechnical-drilling.webp` has been removed from both the registry and disk. Its existing sector slot now contains an original, explicitly labelled schematic of ground layers and a borehole, rather than unrelated stock photography.
